# First Day Entertainment

First Day Entertainment Inc. is a Sunnyvale, California game studio building AI-powered games,
founded by Stephen Gou (formerly a founding engineer at Cohere) and Mike Mei, and funded by the
a16z SPEEDRUN accelerator (batch 002) and MiraclePlus.

The studio ships two titles:

- **Heroes of Magic & Cards** — a poker deckbuilding roguelike, on [Steam](https://store.steampowered.com/app/3843360/Heroes_of_Magic__Cards/).
- **Mana Land** — a single-player RPG where players adventure alongside conversational AI companions, on [itch.io](https://firstdaygg.itch.io/mana-land).

Website: https://www.firstdayentertainment.net/

## API surface

None. As of the 2026-07-20 enrichment pass, First Day Entertainment publishes no developer portal,
API reference, OpenAPI/AsyncAPI description, SDKs, CLI, MCP server, webhooks, sandbox, or
`/.well-known/` discovery document. Its AI is embedded in its games rather than exposed as a
service. This repo therefore carries company identity plus infrastructure probes only.
